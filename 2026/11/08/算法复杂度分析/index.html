算法复杂度分析

本文最后更新于 2026年11月9日 晚上

时间复杂度

记号

上界、下界、紧界

设 $f,g$ 最终非负，下面的不等式都要求对充分大的 $n$ 成立，即存在 $n_0$，对所有 $n\ge n_0$ 成立。

记号 含义 条件
$f(n)=O(g(n))$ upper bound（上界） 存在 $c>0$，$f(n)\le cg(n)$
$f(n)=\Omega(g(n))$ lower bound（下界） 存在 $c>0$，$f(n)\ge cg(n)$
$f(n)=\Theta(g(n))$ tight bound（紧界） 存在 $c_1,c_2>0$，$c_1g(n)\le f(n)\le c_2g(n)$

下面介绍常用方法

代入法

猜测一个界,然后用归纳法证明其正确性

例子1

$T(n) = T(n - 1) + T(n - 2)$, 求解T(n)的渐进表达

猜测为 $\Theta(c^n)$, 即 $$kc^n \le T(n) \le k’c^n (k, k’, c>0)$$
归纳得: $$kc^{n - 2}(c + 1) \le T(n) \le k’c^{n - 2}(c + 1)$$
欲使 $$RHS = c^{n - 2}(c + 1) = c^n$$
解得 $$c=\frac{1 + \sqrt{5}}{2}$$
即得$$T(n) = \Theta((\frac{1 + \sqrt{5}}{2})^n)$$

递归树

将递归式转化为树, 节点表示递归调用的代价

主方法

主方法依托于主定理(Master Theorem).

主定理适用条件与三个情形

主定理处理 $T(n)=aT(n/b)+f(n)$，其中 $a\ge 1$、$b>1$ 都是常数，$f(n)$ 最终非负.

情形 需要的条件 时间复杂度
1 $f(n)=O(n^{p-\varepsilon})$，某个常数 $\varepsilon>0$ $\Theta(n^p)$
2 $f(n)=\Theta(n^p(\log n)^k)$，某个常数 $k\ge 0$ $\Theta(n^p(\log n)^{k+1})$
3 $f(n)=\Omega(n^{p+\varepsilon})$，某个常数 $\varepsilon>0$，并且对充分大的 $n$ 有 $af(n/b)\le c f(n)$，某个常数 $0<c<1$ $\Theta(f(n))$

出于篇幅，略去其繁琐证明

例子1(Strassen算法)

给出Strassen算法的递推式:
$$T(n)=7T(n/2) + \Theta(n^2)$$
则$a = 7, b = 2, f(n) = \Theta(n^2)$
应用情形1,得$$T(n) = \Theta(n^{\log{7}})$$

例子2(Merge Sort)

给出递推式:
$$T(n) = 2T(n/2) + \Theta(n)$$
则$a = 2, b = 2, f(n) = \Theta(n)$
应用情形2,得$$T(n) = \Theta(nlogn)$$

主方法只能处理每层均分的、$f(n)$满足特定条件的情形,没有覆盖$f(n)$.
其不能解决的可以通过递归树 + 归纳解决,但事实上Akra-Bazzi定理给出了更强的结论.

Akra-Bazzi 定理

形式与条件

沿用 CLRS 的记号，考虑

$$T(n)=\sum_{i=1}^{k}a_iT(n/b_i)+f(n).$$

使用前检查以下条件：

  1. 分支固定：$k$ 是固定正整数，所有 $a_i>0$、$b_i>1$ 都是常数，不随 $n$ 改变。
  2. 递归有终点：规模不超过某个固定阈值 $n_0$ 时，$T(n)=\Theta(1)$。
  3. 额外成本有效：$f(n)$ 对充分大的 $n$ 为正，并在所用的有限积分区间上可积（连续函数即可）。
  4. 相近规模的成本相差不超过常数倍：存在固定常数 $C\ge1$，使充分大的 $n$ 和所有 $u\in[n/2,n]$ 都满足

$$\frac1C\le\frac{f(u)}{f(n)}\le C.$$

第 4 条就是 polynomial-growth condition 的一种等价写法：输入规模在 $n/2$ 到 $n$ 之间变化时，$f$ 不能出现超过固定常数倍的涨落。这里的 $C$ 不能依赖 $n$ 或 $u$，也不能只检查 $u=n/2$ 这一个点。

常见形式可以直接判断：若 $f(n)=\Theta(n^\alpha(\log n)^\beta)$，其中 $\alpha,\beta$ 为固定实数，就满足第 4 条。

$f(n)$ 是否满足第 4 条
$1,\ n,\ n^2$ 满足
$\log n,\ n\log n,\ n/\log n$ 满足
$1/n$ 满足；不要求 $f$ 单调递增
$2^n$ 不满足：$f(n/2)/f(n)=2^{-n/2}\to0$，不存在固定的正下界 $1/C$

注意，仅知道 $f(n)=O(n^d)$ 还不够，还需控制它在相近规模间的涨落。

定理内容

先找到唯一的实数 $p$，使

$$\boxed{\sum_{i=1}^{k}\frac{a_i}{b_i^p}=1}.$$

则

$$\boxed{T(n)=\Theta\left(n^p\left(1+\int_{n_0}^{n}\frac{f(u)}{u^{p+1}},du\right)\right)}.$$

这里把积分下限放在固定阈值 $n_0>1$，避免 $1/\log u$ 等函数在小规模处无定义。若 $f$ 在 $[1,n_0]$ 上的相应积分有限，也可以采用常见的下限 $1$；结果同阶。

直观理解：$n^p$ 给出递归结构的基准量级，积分项描述各个规模上的额外工作如何累积。

括号中的 $1$ 不能漏掉：即使积分收敛到常数，仍然有 $\Theta(n^p)$ 的成本。

这里给出结论，不展开证明.原

例子1：不等规模的分支

$$T(n)=T(n/3)+T(2n/3)+n.$$

步骤 内容
识别 $a_1=a_2=1$，$b_1=3,b_2=3/2$，$f(n)=n$
求解 $p$ $(1/3)^p+(2/3)^p=1$，得 $p=1$
积分 $\int_{n_0}^n u/u^2,du=\ln(n/n_0)=\Theta(\log n)$
结果 $T(n)=\Theta(n(1+\log n))=\Theta(n\log n)$

例子2：不必精确求出 $p$

$$T(n)=T(n/5)+T(7n/10)+n.$$

由于 $7n/10=n/(10/7)$，这里 $a_1=a_2=1$，$b_1=5$，$b_2=10/7$。对应方程为

$$\frac{1}{5^p}+\frac{1}{(10/7)^p}=1.$$

左边关于 $p$ 递减：$p=0$ 时为 $2$，$p=1$ 时为 $9/10$，所以 $0<p<1$。这一点已经够用：

$$\int_{n_0}^n\frac{u}{u^{p+1}},du=\int_{n_0}^n u^{-p},du=\Theta(n^{1-p}).$$

故

$$T(n)=\Theta\left(n^p(1+n^{1-p})\right)=\Theta(n).$$

技巧：先看积分需要知道 $p$ 的哪些信息。若只需判断 $p<1$，就不用继续求数值近似。

例子3：补上主方法的空隙

$$T(n)=2T(n/2)+\frac{n}{\ln n}.$$

这里用 $\ln$ 表示自然对数，换成其他固定底数不改变结论。

由 $2/2^p=1$，得 $p=1$。驱动函数比 $n$ 小，却没有小一个 $n^\varepsilon$ 因子，因此前面的主定理不能直接处理。

Akra-Bazzi 给出

$$\int_{n_0}^n\frac{u/\ln u}{u^2},du=\int_{n_0}^n\frac{1}{u\ln u},du=\ln\ln n-\ln\ln n_0.$$

故 $T(n)=\Theta(n\log\log n)$。

摊还分析（Amortized Analysis）

摊还分析用来评价某个数据结构的一系列操作的平均代价, 有三种常用的技术：聚合分析，核算法，势能法。

聚合分析（Aggregate Analysis）

若任意 $m$ 次操作的总成本至多为 $F(m)$，统一分摊后，每次成本至多为 $F(m)/m$

核算法（Accounting Method）

赋予一个操作摊还代价$\widehat c_t$,该操作真实代价为$c_t$.
当$\widehat c_t > c_t$时, 定义$\widehat c_t - c_t$为信用(credits)
为了确保摊还代价的和能给出真实代价的上界, 要求:
$$\sum_{t=1}^n \widehat c_t \ge \sum_{t=1}^n c_t$$即总信用始终为非负值

势能法（Potential Method）

给每个数据结构 $D$ 定义势能 $\Phi(D)$
定义摊还代价
$$\widehat c_t=c_t+\Phi(D_t)-\Phi(D_{t-1}).$$

求和:
$$\sum_{t=1}^n \widehat c_t=\sum_{t=1}^n c_t+\Phi(D_n)-\Phi(D_0).$$
同样的,我们要求:
$$\Phi(D_n)-\Phi(D_0) \ge 0$$
通常简单定义$\Phi(D_0)=0$

如何选择

已知 适合的方法
能直接数清整串操作的总工作量 聚合分析
能把未来的工作归到某次操作或某个元素上 核算法
能用当前状态描述尚待完成的工作 势能法
