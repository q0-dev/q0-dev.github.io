从不变量的角度重新审视算法与数据结构

本文最后更新于 2026年11月17日 晚上

你是否认为写对二分、多指针算法是玄学?
数据结构为什么要那样设计?
本文将从不变量的角度谈谈笔者的理解

什么是不变量(invariant)?

不变量不是常量, 笔者认为解释为恒定的规律/关系是合适的。 常见的不变量:

  • 算法中的不变量:

    • 滑动窗口: [left, right] 内的子数组是满足要求的合法区间
    • …

  • 数据结构中的不变量

    • 单调栈: 栈里的元素从栈底到栈顶保持单调
    • AVL 树: 任意节点的左右子树高度差绝对值 $\le 1$
    • …

可见:

维护不变量一方面是为了满足特定要求(算法), 同时也相当于增强了条件(数据结构), 进而使结构有一些好的性质(比如降低最坏情况的时间复杂度)。

如何应用不变量

流程:

  1. 确定不变量(根据特定要求、需要的条件等)
  2. 维护不变量
  • 初始化($n=1$)
  • 保持($n=k \implies n=k+1$成立)
  • 终止(结合不变量与退出条件推出所需结果, 并另外证明算法会终止)

是的, 应用不变量实际上是一个归纳的过程。

这样就保证了算法满足要求, 数据结构满足好的性质。

下面笔者将从算法和数据结构两方面谈谈不变量的具体应用（下文涉及的复杂度分析方法可参考笔者的另一篇文章：算法复杂度分析）。

算法中的不变量应用

例1(插入排序)

不变量: nums[0 ... i-1] 由原数组前 i 个元素组成，且内部有序

  • 初始化: i=1自然成立
  • 保持: 每次新插入元素都与前面元素比较,放入正确位置
  • 终止: 结果有序

参考代码:

  • 复杂度分析（直接加和）：
    • 记 $n = \text{length}$。最好情况（已升序）每轮比较 $1$ 次，$T(n) = \Omega(n)$；
    • 最坏情况（逆序）$T(n) = \sum_{i=1}^{n-1} i = \Theta(n^2)$，故时间复杂度为 $O(n^2)$；
    • 原地交换，空间复杂度 $S(n) = \Theta(1)$。

例2(选择排序)

以升序为例.

不变量: nums[0..i-1] 是全数组最小的 i 个数, 且内部有序

  • 初始化: i=0, 前缀为空, 自然成立
  • 保持: 找 nums[i..length-1] 中的最小值, 与 nums[i] 交换
  • 终止: 结果升序
  • 复杂度分析（直接加和）：
    • 内层循环固定比较 $n - 1 - i$ 次，$T(n) = \sum_{i=0}^{n-2}(n - 1 - i) = \Theta(n^2)$；
    • 空间复杂度 $S(n) = \Theta(1)$。

例3(二分查找)

以升序数组、闭区间 [left, right] 为例.

不变量: 若 target 存在, 则其下标必在 [left, right] 内

  • 初始化: left = 0, right = length - 1, 覆盖全数组, 自然成立
  • 保持: 比较 nums[mid] 与 target, 排除不满足的一半, 令 left = mid + 1 或 right = mid - 1
  • 终止: 找到 target 返回, 或 left > right 区间为空, 说明不存在
  • 复杂度分析（建立递推 + 主方法）：
    • 每轮规模减半，最坏情况 $T(n) = T(n/2) + \Theta(1)$，由主定理情形 2 得 $T(n) = \Theta(\log_2 n)$（整体 $O(\log_2 n)$）；
    • 空间复杂度 $S(n) = \Theta(1)$。

例4(快速排序 partition)

多指针的本质是用指针作隔板, 划分已知区与未知区.

选 pivot = nums[length - 1], 维护快慢指针 i, j:

不变量: nums[0..i-1] < pivot, nums[i..j-1] >= pivot, nums[j..length-2] 待扫描

  • 初始化: i = 0, j = 0, 前两个区间为空, 自然成立
  • 保持: 若 nums[j] < pivot, 交换 nums[i] 与 nums[j] 并 i++; 随后 j++
  • 终止: j = length - 1 扫描完毕, 交换 nums[i] 与 nums[length - 1], pivot 归位
  • 复杂度分析（直接加和）：
    • j 单次线性扫描，单次划分 $T(n) = (n - 1)\cdot\Theta(1) = \Theta(n)$，
    • 空间复杂度 $S(n) = \Theta(1)$。

例5(滑动窗口)

以下模板求最长合法区间.

不变量: 每轮收缩结束后, [left, right] 为满足条件的合法区间

  • 初始化: left = 0, ans = 0, 加入第一个元素前窗口为空
  • 保持: 移入 nums[right]; 若破坏合法性, 则不断 left++ 移出左端元素直至重新合法; 随后 right++
  • 终止: right 到达末尾, 已考察每个右端点对应的最长合法窗口
  • 复杂度分析（摊还分析 - 聚合分析）：
    • 设单步操作为 $\Theta(1)$。每个元素随 right++ 入窗 $1$ 次、随 left++ 至多出窗 $1$ 次，总入窗、出窗次数 $\le 2n$，故总时间 $T(n) = \Theta(n)$，每轮外层迭代摊还 $\Theta(1)$；
    • 空间复杂度 $S(n) = \Theta(1)$。

数据结构中的不变量应用

数据结构 不变量 维护方式 获得的性质
链表 (LList) length 等于实际节点数; 双向链表在 p->next 非空时有 p->next->prev == p 插入/删除时同步更新 length 与前后指针 $\Theta(1)$ 获取长度、$\Theta(n)$ 双向遍历
单调栈 栈底到栈顶单调 入栈前弹出所有破坏单调性的栈顶元素 均摊 $\Theta(1)$ 找最近更大/更小元
二叉堆 (Heap) 完全二叉树 + 父节点 $\ge$ 子节点 尾插后上浮 (sift_up), 弹出堆顶后下沉 (sift_down) $\Theta(1)$ 查最值, 插入/删除堆顶最坏 $\Theta(\log n)$（不计扩容）
AVL 树 BST 性质 + 左右子树高度差的绝对值 $\le 1$ 插入/删除失衡时左旋、右旋 树高维持 $\Theta(\log n)$

例1(单调栈)

求每个元素右侧第一个更大元素的下标.

不变量: 栈内下标对应的元素从栈底到栈顶单调不增

  • 初始化: 栈空, 自然成立
  • 保持: 新元素 nums[i] 入栈前, 持续弹出 $< \text{nums}[i]$ 的栈顶元素, 再将 i 入栈
  • 终止: 遍历结束, 栈中剩余元素右侧无更大值
  • 复杂度分析（摊还分析 - 核算法/聚合分析）：
    • 每个下标入栈 $1$ 次、至多出栈 $1$ 次（入栈时赋摊还代价 $\widehat c_i = 2$，预存 $1$ 单位信用支付出栈），总时间 $T(n) = \Theta(n)$，单次摊还 $\Theta(1)$；
    • 空间复杂度 $S(n) = \Theta(n)$。

例2(二叉堆 push)

以大顶堆为例.

不变量: 完全二叉树, 且任意非根节点满足 heap[(i - 1) / 2] >= heap[i]

  • 初始化: 单节点或空堆自然成立
  • 保持: 新元素置于数组末尾(保持完全二叉树), 若大于父节点则不断交换上浮
  • 终止: i == 0 或满足父节点 $\ge$ 当前节点, 堆序恢复
  • 复杂度分析（直接加和）：
    • 完全二叉树不变量保证树高为 $\lfloor\log_2 n\rfloor$，上浮至多交换 $\lfloor\log_2 n\rfloor$ 次，时间复杂度为 $O(\log_2 n)$（最坏 $\Theta(\log_2 n)$）
    • 原地交换，空间复杂度 $S(n) = \Theta(1)$。

结语

写出正确的二分查找并非玄学，多指针的移动也并非无章可循——算法的每一步推进、数据结构的每一次调整，本质上都是在状态变化中维护不变量的归纳过程：不变量赋予了算法正确性的根基，也赋予了数据结构低复杂度的保证。

正如数学家兼哲学家怀特海（Alfred North Whitehead）所言：

“The art of progress is to preserve order amid change and to preserve change amid order.” （进步的艺术，是在变化中保持秩序，在秩序中保持变化。）
