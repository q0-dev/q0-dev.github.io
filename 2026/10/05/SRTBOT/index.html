SRTBOT

本文最后更新于 2026年10月6日 凌晨

MIT6.006中给出了SRTBOT的dp算法设计方法，本文记录笔者的理解。

框架解释:

步骤 名称 说明
S Subproblems 定义子问题（下文记为 subprobs）
R Relate subproblems recursively 用更小的子问题递归地表示
T Topological order on subprobs 确定求解顺序（保证 DAG，读者不妨思考原因）
B Base case 关系无法继续展开时直接给出答案
O Original problem via subprobs 原问题对应哪个子问题
T Time analysis 时间分析

例子1(Bowling):

  • 给定 n 个球瓶，编号 $0, \dots, n-1$
  • 球瓶 $i$ 的价值为 $v_i$
  • 击中 1 个球瓶 $i$，得 $v_i$ 分
  • 击中相邻 2 个球瓶 $i$ 和 $i+1$，得 $v_i \cdot v_{i+1}$ 分
  • 球瓶被击中后即被移除，不能再被击中
  • 目标：扔出 0 个或更多球，最大化总分

按 SRTBOT 展开：

步骤 内容
S $B(i)$：只考虑球瓶 $[i, n-1]$ 时的最大得分
R $B(i) = \max(v_i + B(i+1),\ v_i \cdot v_{i+1} + B(i+2),\ B(i+1))$
局部穷举三种选择：单独击中 / 一起击中 / 跳过
T $i$ 递减
B $B(n) = B(n+1) = 0$
O $B(0)$
T $\Theta(n) \cdot \Theta(1) = \Theta(n)$（下面会给出一般方法）

不难发现，解决的关键在于S和R，而二者又是紧密联系的；下面给出S和R的选取技巧。

S:

  • subsets of input: prefix, suffix, substring(contiguous), 具体选择根据问题特征，通常前两个可以互换
  • multiply possible subsets across multiple inputs (这里的multiply笔者认为可以理解成笛卡尔积)
  • record partial state by add auxiliary variables (当R处理困难时，通过增广记录状态简化R)

R: Guess + Induction

  • 处理recursive的问题，归纳验证是通法

例子2(Fibonacci):

  • $F_n = F_{n-1} + F_{n-2}$, $F_0 = 0$, $F_1 = 1$
  • 给定 $N$，求 $F_N$?

使用前文提到的SRTBOT方法(S, R几乎是显然的):

步骤 内容
S $F(i)$：第 $i$ 个 Fibonacci 数
R $F(i) = F(i-1) + F(i-2)$
T $i$ 递增
B $F(0) = 0$，$F(1) = 1$
O $F(N)$

T: $T(n) = T(n-1) + T(n-2) + O(1) > 2T(n-2)$, 指数级… :(

聪明的读者肯定发现了问题：$F(k)$（$1 \le k \le n$）被计算了 $F(n-k+1)$ 次！
问题在于：DAG 被朴素递归展开成了 tree！
